## 4. Review (separate agent, before the final build)

Findings and what was done:
1. File blocks' READ/WRITE with maxSdkVersion would make their onCreate check ask again at every start on Android 11-12
   → reverted; the File blocks' declarations are as before (only the permission blocks' own entries get maxSdkVersion).
2. The int converter read `<<` / `>>` as comparisons and accepted `n = 0; total = total + n;` → operators read longest
   first, one statement per line, `*`, `/`, `%` and `=` keep an int (section 3).
3. A permission block in a Fragment left the helper's one-dialog lock set (no activity passed the answer back) → every
   activity of a project that uses the blocks gets the result code.
4. Android 4.4-5.1's DownloadProvider enforces WRITE_EXTERNAL_STORAGE for any file destination (AOSP 4.4_r1 / 5.1.1_r38
   read; 6.0.1 / 7.0 only for shared folders) → WRITE max 22 for "allow downloads" when min SDK < 23.
5. `{host}` replaced in every custom block → only in the new blocks.
6. A custom event / MoreBlock named onPermissionGranted / onPermissionDenied clashes → known limit (README).
7. Permissions written after the blocks' (components, manifest injection) could duplicate → the blocks' entries are
   written last, deduped against the manifest text written so far. READ_MEDIA_IMAGES / VIDEO and Play's photo policy →
   put to the owner (release notes).
8. An interrupted dialog (empty answer) reported as "never ask again" → not any more.
