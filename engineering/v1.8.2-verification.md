## Facts found while checking
- `com.github.gabriel-TheCode:AestheticDialogs:1.2.0` does not exist on JitPack (HTTP 404). `1.0.0` exists and
  has `public static void showToaster(Activity, String, String, String)`; `1.3.6` exists and has no static API.
  The engine therefore restores/installs 1.0.0.
- The bundled zipalign pads its output when nothing needed aligning (aapt2: "extraneous bytes"); exports on
  Android 8+ no longer use it, the old path trims the padding.

## Not done in this release
- Google sign-in gate, Credential Manager, Firebase: needs `google-services.json` and the toolchain bump
  (see `auth-telemetry-review.md`); the APK is still signed with the test key.
- apksig 35 / 16 KB alignment of users' `.so` files, read-only flag for Kotlin plugin jars: see `android15-audit.md`.
- Java 17: see `java17-path.md` (ECJ 3.26 rejects `-17`; not offered).
