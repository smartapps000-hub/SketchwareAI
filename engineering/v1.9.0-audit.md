## 4. Emulator

No Android emulator can run here: the build machine has no `/dev/kvm` (hardware virtualisation). The runtime checks are
the ART harness (the APK's own classes on the Android 12 / API 31 runtime, without the framework) and layoutlib
(Android 14's view code on the JVM). Activities, the window (insets, back gestures) and installing the APK are tested on
the owner's phone.
