## 2. Web engine

Today: WebView with loadUrl, back / forward, zoom, cache mode, clear cache / history, stop. Requested: download listener
→ DownloadManager (headers, notification, destination), allowed MIME types, progress, user agent, file chooser
(`onShowFileChooser`, camera / gallery), fullscreen video (`onShowCustomView`), geolocation prompt, SSL error dialog,
cookies. Each is a block whose code is a listener or client set on the WebView; they can be built as extra blocks (as
`mod.hasrat.blocks.ExtraBlocks` does) with a small generated helper class. Two rules apply: no permission is added
silently (camera, location: the block says it needs them, the user adds them in the Permission manager), and an "SSL
error bypass" block is not built (it makes every connection of the app interceptable); an SSL error dialog is.
Estimate: 2-3 days for downloads + file chooser + fullscreen + user agent + cookies, with an ART fixture that compiles a
project using every block.

## 3. (i) visual docs

The block drawer and the palette are upstream's precompiled classes (`LogicEditorActivity` palette rows, `PaletteWidget`).
A (i) badge on each block needs a long-press (or a small overlay) hook in the drawer and a docs sheet; the content per
block (shape, where to drop it, what to plug in, what happens) can be generated from the block's spec and opcode plus a
short text table. Plan: a `BlockDocs` table (opcode → 3 steps, written for the most used blocks first), a Material 3
bottom sheet that draws the block with the editor's own block view (`Rs`) and the three steps; long-press in the drawer
opens it. Estimate 2 days; Activity code, so its first check is on the owner's phone.

## 5. Suggested order

1. Web blocks (downloads, file chooser, fullscreen video, user agent, cookies) — self-contained, high value.
2. Java → blocks: if / else / repeat with bodies (sub-stacks), then int locals with a use check.
3. XML editor (deep audit section 3).
4. M3 widget suite in waves: Slider + progress indicators + Chip / ChipGroup; then NavigationRail / SearchBar / ExtendedFAB.
5. (i) docs sheet for the blocks of 1 and 4 first.
6. Media3 / location / Firebase migration (min SDK 23 for projects that use them).
