# v1.8.6 verification

Final APK: `v1.8.6-9bc690c-minApi26` (versionCode 176), built from commit 9bc690c (the docs commit after it changes no
code). Requests (owner, 23 Oct 2026, after testing v1.8.5 on his phone): Build Settings buttons covering an option;
Material 3 on by default for new projects with D8 / Java 11 / desugaring / 16 KB aapt2; real Material 3 colours
(tonal palette, surfaces, DayNight, dynamic colour), outlined fields and pill buttons that hold up, canvas parity;
publish to GitHub.

Where things ran: **ART** = the APK's own classes on the Android 12 (API 31) ART runtime without the framework
(`tools/art-harness`); **LAYOUTLIB** = Android 14's view/theme/text code on the JVM (`tools/layoutlib-renders`);
**HOST** = desktop tools; **review** = a separate agent reading the code. No device, no emulator (no hardware
virtualisation on the build machine).

## 6. Review before release

A separate agent reviewed the diff: 1 high, 3 low.
1. (high) DesignActivity keeps one `yq` for all Run builds and `yq` read the project settings once: turning Material 3 on
   in the Library Manager mid-session made M3Widgets wrap fields with `AppTheme.TextField` while styles.xml came from
   the old branch (aapt2: style not found); Dark theme / Dynamic colour switches did nothing until the project was
   reopened. Fixed: `yq` re-reads the settings at every generation.
2. (low) canvas screen-root colour stale after a toggle, and the collection preview could take a project's palette.
   Fixed: roots refreshed after `DesignTheme.load`, palette only in DesignActivity's panes.
3. (low) canvas draws a code-kept-plain button as a pill: documented limit.
4. (low, risk) dark theme default: colours the user picked stay as set at night; the Dark theme row says so.
The fixes were checked by the same agent (OK). Found correct: ItemLinearLayout matches the removed bytecode, every theme
attribute and style exists in Material 1.13 / AppCompat 1.7.1, the night file path, DynamicColors before super.onCreate,
SketchTextField API guards, Library Manager tags, no change for non-Material 3 projects.
