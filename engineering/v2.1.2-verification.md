## 4. Reviews

Three separate review passes of the diff (an agent; code reading, nothing run; the first one stopped at the 5-hour
usage limit and was resumed after the reset).

First pass (the whole v2.1.2 diff): no HIGH; 3 MEDIUM, 10 LOW, all fixed except one LOW kept as a limit:
- MEDIUM: a shared GitHub link (CLEAR_TOP) closed Home when the GitHub tab was kept behind it, and Back then left the app
  → `REORDER_TO_FRONT | SINGLE_TOP`, the tab marks kept.
- MEDIUM: an update that finished while the app was in the background tried to open the installer (Android refuses it)
  and its notification was already gone → "Tap to install" notification unless the app is in front.
- MEDIUM: Back on a Home opened by a file manager (.swb) sent the file manager's task away → closes back to it.
- LOW: the update notification reordered Home over an inner page (now the launch intent); kept Restore tabs showed another
  account's projects (rebuilt when the account changes); a download notification left by a stopped process (cleared at
  start); the code pages' hint overwritten; a deleted project in the kept list; a failed counter read answered as "no
  counters"; "?" as an empty monogram; one bad app-control field voided the file; the install / update lines on the card
  forever (three days now). Kept: two phones of one model both stay signed in until the older one writes its key (it is
  required to update).

Second pass (those fixes): no HIGH or MEDIUM; 5 LOW, all fixed: a Home in another app's task closes with the tabs it
opened (`finishAffinity`); a stray inner page brought forward as a tab closes and the real tab comes; kept Demo / On this
phone tabs keep their scroll (the phone tab rebuilt only when the backups folder changed); a list read in flight dropped
after a delete; the notification read at start guarded.

Third pass (those fixes): no HIGH or MEDIUM; the finish-and-ask-again step can't loop or make a second tab; 3 LOW: a second
Home from a .swb now closes and brings the first forward; the list is read again after a delete; kept as a limit: a .swb
added inside a backups subfolder by another app isn't noticed by a kept On this phone tab until its sub-tab is tapped.
