## Not changed, and why

- `int` / `long` / `float` locals stay custom variables (`private int x;`, assignment as code). A Number variable is a
  `double`: `String.valueOf(x)` would show `3.0`, and `list.get(x)`, `switch (x)`, `array[x]` would no longer compile.
  The Java editor's proof compares the code text, so it can't catch a type change; converting them is the owner's call.
