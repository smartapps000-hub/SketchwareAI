## 4. Reviews

Three separate review passes (agents; code reading, nothing run).

First pass (the whole diff): no HIGH; 3 MEDIUM, 12 LOW, all fixed:
- MEDIUM: followers would have been notified at every backup (GitHub's push time) → news from the store page's own
  `published_at`.
- MEDIUM: a JSON setter with an empty path replaced the whole variable → setters change nothing with an empty path; "set
  JSON" replaces the whole only for empty text or JSON.
- MEDIUM: the scrolling @creator pill was drawn pressed (selected state) → own background without a selected look.
- LOW: country fixed at Publish as shown and named in Make it public?, "Don't show" per account; notice ids in their own
  range; BOM; deep nesting; documented leniency; a reader cache; a value in the way kept; Following fits at large fonts;
  notification question at most every 3 days with Settings after a refusal for good; notices only after a Follow in the
  app; a tapped Follow kept against a list read in flight; record committed before the job ends; GitHub Mobile only on
  GitHub's sign-in pages.

Second pass (those fixes and the whole diff again): no HIGH; 1 MEDIUM, 10 LOW, all fixed: an app whose page couldn't be
read at the first look was announced later (first-look time kept once); same-version re-publishes and notices without
title / version; a stale read undoing a tap; the Follow recorded on the worker; a dead Allow after other questions; a focus
ring left by the marquee trick (replaced); a write-out overflow emptying the variable; guide wording; the share pill cut
and ignoring Don't show; the job's stop flag.

Third pass (those fixes): no HIGH; 2 MEDIUM, 7 LOW, all fixed: NaN / Infinity read into an array made org.json write null
(a NullPointerException in the generated helper) → readers give empty text, setters keep the JSON; the 512 KB cache cap
(a big answer re-parsed in a loop) → softly held cache; the record per account and cleared when following no one; first
looks on GitHub's clock (Date header); an app without a version code counts only when new; no Settings message after an
interrupted or dismissed permission question; the share pill up to three lines and the saved forms; guide wording.

## 6. Decisions left to the owner

- Notices for followed creators are on after the first Follow in the app; a switch to turn them off in the app (beside
  Android's own channel setting) can be added.
- Creator levels stay automatic from public data (rules shown with the badge); a manual "trusted" list kept in the
  repository is possible on request.
- GitHub Mobile can't be answered by another app; the e-mailed code is the in-app way.
- Git LFS: with v2.1.5 the `binaries` branch holds about 4.8 GB of the free 10 GiB storage; every phone on v2.1.4
  downloads the 143 MB APK once.
