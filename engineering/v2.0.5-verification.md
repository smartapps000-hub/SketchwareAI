## 4. Reviews

A separate agent reviewed the v2.0.5 diff three times. Pass 1 (HIGH 1, MEDIUM 5, LOW 9): the Demo row never drawn on
the first load (HIGH); cancel / pause lost when Android's HTTP stack clears the interrupt flag (two uploads of one
project after the watchdog); a resumed backup ignoring icon / resource / list-entry / library changes; interrupted NIO
calls throwing the checkpoint away; a false "refused" mark from a 5xx / 429 / 403 after a 401; saved public details
overwritten by a running backup; LOW: abandoning while packing or restoring, stopAskedAt not reset after packing,
resume file leaks, the viewer (downloads killed on leaving, two taps on one file, a destroyed-screen crash, Keystore on
the main thread), notification spam while refused, Sign in again rerunning nothing for a joined tap, demo detection
hiding copies, drawer pills cut, paused jobs' watchers and the 96% note. Pass 2 (MEDIUM 1, LOW 5): a malformed
`demo.json` from someone else's backup crashing the projects screen; cleanup by file age, inputs recorded after
packing, a library path walking wide folders, a lost download end, saves while refused re-uploading unchanged projects.
Pass 3 (LOW 1): library folders compared as path text. All fixed (commits 807aaac, b0da3ab, a4af953, 1bc8cc1).
