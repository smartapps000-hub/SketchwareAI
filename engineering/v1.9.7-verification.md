## 2. Review (separate agent, two passes before the final build)

Pass 1, no blockers: the post-download rename by file bytes never ran for standalone downloads, left the download
manager's notification pointing at the old path and read a file on the main thread → removed (names are settled before
enqueue); URL fragments such as `/tracking/`, `=ads&`, `/beacon` matched ordinary pages and could cancel a navigation →
navigation stops only for listed ad hosts, the broader match only for sub-resources; a custom download type could
carry a quote into the generated string → strict characters; a `[` without `]` in a block text.
Pass 2, no blockers: brand words matched anywhere in a URL (`adservice` in `/FileUploadService/`, `adroll` in
`breadrolls.jpg`, `doubleclick` in `jquery.doubleclick.min.js`) → words only in the host at the start of a label;
Back skipped legitimate pages (`google.com/search?q=adsense`) and did so in every WebView project → listed ad hosts
only, and only while that WebView's ad blocking is on; hiding CSS matched `download-box`, `head-banner`,
`uploads-list` → anchored on whole class names; googletagmanager no longer blocked; the category ending was added
before the server was asked → now a fallback after the HEAD answer. Clean in both passes: the download receiver, the
cache rename, the generated Back chain (several WebViews, drawer), the format slots, API levels, both ICU patterns (run
on ART).
