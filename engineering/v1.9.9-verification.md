## 4. Not built or changed from the ask, and why

- **Owner-only bypass for `smartapps000-hub`**: a check on an account name is readable in the public source and in
  the APK, so anyone could use it; it would also only work after a sign-in, which is what the gate asks for anyway.
  The owner signs in like everyone else (one tap).
- **The gate never locks anyone out for good**: an offline IDE that can't be opened without GitHub breaks the
  offline-first rule. Sign-in is required only when `app-control.json` was read from GitHub in this run (the network
  works), and not for the rest of the run after a sign-in failed for a reason the user can't fix (device sign-in off
  for the OAuth app, no Client ID, Keystore can't store it, no browser). The repository keeps
  `"require_login": false`; the owner flips it on GitHub (no new APK) once sign-in works on his phone. Review finding:
  without these conditions a cached `true` locked an offline or Keystore-broken phone out of its own projects.
- **"Hardware lock"**: what is built binds the saved sign-in, not the APK: the Keystore key never leaves the phone,
  and the associated data ties the ciphertext to ANDROID_ID (per signing key, user and device since Android 8; changes
  after a factory reset), the signing certificate and the GitHub user id. It does not stop a modified APK (the public
  test key signs every release; v1.9.8 section 4).
- **CLEAR_TOP / SINGLE_TOP as the way back**: kept only as a fallback (section 1); `finishActivity` on the Custom Tab
  is the main route because Android 15 refuses most background starts.
- **Two local projects with the same name and package** share one backup file (`projects/<package>/<name>.swb`, so a
  backup made on another phone matches its project): both rows show the same backup. Known limit, as in v1.9.8.

## 5. Device checks (the owner)

1. Install v1.9.9 over v1.9.8 (no uninstall). Main menu > **Cloud Sync & Account** > **Sign in** (the v1.9.8 sign-in
   is not carried over).
2. Paste the code in Chrome, approve. Expected: the Chrome tab closes by itself and the screen shows your picture and
   @smartapps000-hub. If the tab stays open: tap X; the screen must show the signed-in card at once.
3. Back up a project (toast), Restore it (a new project appears in the list).
4. Only after 2 and 3 work: `"require_login": true` in `config/app-control.json` on GitHub, restart the app twice
   (the first start reads the file); the sign-in screen must not open while signed in; sign out: it must open, Back
   leaves the app.
5. Projects #644, #623, #606: Run each once.

If something fails: long-press the red line under the button (copies the cause), or the compile log (Copy).
