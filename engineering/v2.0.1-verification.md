## 4. Changed from the ask, or not built, and why

- **User agent unchanged ("; wv" not removed).** Google detects embedded WebViews by that mark to refuse its sign-in
  inside apps; removing it to get around that is against Google's OAuth policy (and Google detects WebViews by other
  means too). Google, Apple and passkey accounts use **Sign in via browser**, which the directive asked for as well.
- **No Google Tink.** The token is already AES-256-GCM under an Android Keystore key with the device / certificate /
  account binding as associated data (`TokenStore` v2, v1.9.9); Tink's Android keyset manager wraps the same Keystore
  key, adds about 1-2 MB and brings protobuf-lite, which clashes with the protobuf-java the IDE ships for bundletool.
- **No Credential Manager.** GitHub has no Credential Manager sign-in; the app never sees a GitHub password (GitHub's
  own page does), and putting the GitHub token into a password manager would copy it to that provider's cloud. The
  sign-in already survives restarts and updates (Keystore), and GitHub's cookies are kept in the window, so a second
  sign-in skips the password.
- **OkHttp**: no new library and no rewrite of the network code. OkHttp 4.10.0 is already a dependency of the IDE and
  Android's `HttpURLConnection` is OkHttp underneath; the asked behaviour (longer timeouts for 2G/3G, retries with
  pauses, Retry-After, stopping while GitHub's limit lasts) is in `GitHubHttp`. An HTTP response cache isn't used:
  every GitHub call is authenticated and changes state or must be current; the one list worth having offline (your
  GitHub backups) is kept by the import sheet and shown offline.
- **Backup boxes on by default** (the directive's ☑): GitHub backups can now include local libraries, so they can be
  larger; over 95 MB the backup says to untick Local libraries. The choice is remembered.
- **Local libraries from someone else's GitHub backup** (the directive: "import incl. local libraries"): v2.0.0 never
  copied them; v2.0.1 asks, with "Without libraries" as the main button and a trust note. Copied ones carry
  `imported_from_link.txt`: the build's automatic repair never switches them on in another project, and the Library
  Resolver / download repair install the real Maven artifact over a marked folder of the same name (review findings).
  Libraries already on the phone are never replaced.
- **Rate limits** are paused per credential: GitHub's limit for signed-out calls (shared by everyone on a mobile
  network) never blocks the signed-in account or the account read right after a sign-in (review HIGH finding).
