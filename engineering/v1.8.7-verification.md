# v1.8.7 verification

Final APK: `v1.8.7-b2bdd42-minApi26` (versionCode 177), built from commit b2bdd42 (the docs commit after it changes no
code). Requests (owner, 23 Oct 2026, with his v1.8.6 phone screenshots and a 229 s screen recording of the ASTR Sketchware
Pro mod): a full-screen New Project screen like the recording's (cards: names with icons, template carousel, build engine,
language, theme presets with Generate Random and swatches, SDK settings); no black area under the widgets; then the
Library Resolver, a Direct Java editor that converts code to blocks, a View/res/Code switcher, GitHub push.

Scope of this release: the New Project screen and the bugs found on his phone. The Library Resolver, the Direct Java
editor and the Code tab are the next release (README roadmap item 1). Not offered because they would not work on the phone:
a Gradle build engine (the recording's needs a ~1.5 GB JDK + Gradle runtime on the device, and its Build Release ended
in "APK not found"), Kotlin as the blocks' language (blocks generate Java; Kotlin files work through the Java Manager),
Jetpack Compose (the recording marks it "Coming Soon"; Compose needs the Kotlin 2 compiler plugin).

Where things ran: **ART** = the APK's own classes on the Android 12 (API 31) ART runtime without the framework
(`tools/art-harness`); **LAYOUTLIB** = Android 14's view/theme/text code on the JVM (`tools/layoutlib-renders`);
**HOST** = desktop tools; **review** = a separate agent reading the code. No device, no emulator.

## 4. Generator change: ripple colour alpha

`colors.xml` wrote every colour as #RRGGBB, so `colorControlHighlight` (stored translucent, e.g. #26F4511E) became an
opaque flash on pressed rows. `yq.highlightColor` writes #AARRGGBB when the stored alpha is neither 0 nor 255. This
changes existing projects' ripples too (intended).

7. (low) a failed create left a half-made project → deleted. 8. (low) FAB icon failure silent → logged; fixture 915
   checks the image and `app:srcCompat`. 9. (low) unknown harness `np` spec built the empty template → stops the run.
