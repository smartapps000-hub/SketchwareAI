## 4. Reviews

A separate agent reviewed the v2.1.0 diff twice.

Pass 1 (HIGH 2, MEDIUM 4, LOW 15):
- HIGH: Publish crashed with no saved repository list; the single-device check could sign out the phone that had just
  signed in (a check before its claim landed, or a claim that failed offline).
- MEDIUM: the screenshot viewer read a list another thread was rewriting; a publish was cut off when its screen closed
  (public without the store page) and its end was lost after Hide; update gate gaps (Update never passed the gate,
  Create blocked with nothing to show, a forced update without a link, the empty-list create card bypassed it); the
  checked update APK in shared storage could be swapped before the installer read it.
- LOW: a paused job briefly in no lane; same-name repositories in two lanes; a stale combined notification; the
  install id restored by Android backup onto another phone; sign-in history lost at sign-out; double tab taps; the bar
  left slid away; viewer cache of private repositories after sign-out; the update re-downloaded after "Install unknown
  apps"; an Error from the demo maker; no rebalancing of lanes (left, by design).

Pass 2 on the fixes (MEDIUM 1, LOW 9): the mark's time was the write time, so an offline claim could look newer than a
later sign-in elsewhere, and a sign-in's claim could overwrite a newer mark (now: the sign-in time is written, and a
claim keeps a newer mark); claims marked done for a newer sign-in; an unsaved install id; Create silent when the file
no longer requires the update; the tab debounce ending before the screen shows; Publish's "Reading…" line; the
visibility order; a paused job's sign-in state; posts waiting behind a publish; the installed update left in the cache.

Everything except the lane rebalancing (LOW, by design) and the reviews' mixed-clock note (the comparison uses one
phone's sign-in time against another's; clocks on phones are network-set) was fixed (commits 8495c04, ed691a0).

## 6. Decisions left to the owner

- **Community needs GitHub Discussions on smartapps000-hub/SketchwareAI**: they are off now (the Community tab says so
  with Open on GitHub). Switch them on in the repository's Settings › General › Features › Discussions; reviews of a
  published app need nothing (Publish switches them on for that repository).
- **The single-device lock reverses v2.0.3's "the app never signs out by itself"** for this one case, as the directive
  asks: the phone that signed in last keeps the account; the other one signs out at its next check (startup gate, then
  every 6 hours). Network errors, server errors, rate limits and a refused sign-in never sign out.
- The 401: if it comes back, the refusal note now says when that sign-in was made and last accepted; send a screenshot
  of the card. Many sign-ins on one account (several phones, reinstalls) reach GitHub's 10-token limit per app.
- The personal access token visible in the earlier screenshots was never used or stored; delete it on github.com if
  that hasn't happened.
- GitHub LFS: 23 release APKs of ~140 MB on `binaries` (~3.2 GB of the free 10 GB storage; each download of an APK
  counts against the 10 GB monthly bandwidth).
