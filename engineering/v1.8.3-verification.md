# v1.8.3: what was changed and how each part was checked

Labels: ART = the IDE APK's own classes ran on an Android 12 (API 31) ART runtime in the build sandbox
(`tools/art-harness`, no Android framework, no device). HOST AAPT2 = the x86_64 `libaapt2.so` the APK ships, started by
the IDE's own `ResourceCompiler` from ART. DEVICE = the owner's phone. **Nothing in this file was run on a device.**

## 1. Built-in libraries updated

Every bundled library was re-checked against Maven (Google Maven, Maven Central) on 2026-10-21. A library was updated
to the newest stable version that the IDE's own toolchain can use, read from the published artifact, not assumed:

| Gate | Why | Read from |
|---|---|---|
| `minCompileSdk` <= 33 | user code is compiled and linked against the bundled android.jar (API 33) | `aar-metadata.properties` |
| `minSdk` <= 21 | new projects start at 21 | library `AndroidManifest.xml` |
| Kotlin metadata <= 1.8 | the bundled kotlinc 1.7.10 reads metadata up to 1.8 | `.kotlin_module` header |
| class files <= 55 | ECJ 3.26 + D8 3.3.75 | class headers |
| D8 3.3.75 can dex it | every library is dexed with the D8 the IDE ships | `tools/builtin-libs/package.py` |
| same major for OkHttp 3, Okio 1, Glide 4, Lottie 3 | the generated code is written for them (OkHttp 4/5 and Okio 2+ are Kotlin, Glide 5 and Lottie 4+ change APIs) | |
| every dependency inside the set | Gradle rule: chosen version >= required | POM |

Result: of the 69 libraries the generated code and their dependencies use, 45 updated, 4 new, 6 kept on purpose, 14 already
newest; kotlin-stdlib-jdk7 removed (merged into kotlin-stdlib since 1.8). `libs.zip` now has 116 folders, `dexs.zip` 115
dex files (legacy-support-v4 is resource-only, as before). Full list with each library's gates:
`tools/builtin-libs` output `report.tsv`, copied into `component-library-inventory.md` section 0.

Kept as bundled, with the reason: concurrent-futures 1.1.0 (1.2.0+ class files crash D8 3.3.75 with a
NullPointerException in `CallbackToFutureAdapter$SafeFuture$1`), dynamic-animation 1.1.0-alpha03 and
swiperefreshlayout 1.2.0-alpha01 (newer than the newest usable stable), slidingpanelayout 1.1.0 (1.2.0 drags
androidx.window and coroutines into every project using legacy-support-core-ui; nothing generated uses it),
circleimageview 3.1.0 and listenablefuture 1.0 (already newest).
Left out: error_prone_annotations 2.48+ (Gson 2.14 and Material list it; annotation-only, and its class files crash
D8 3.3.75) and jspecify (annotation-only).
**Not updated (held):** Firebase, Play services (Ads, Maps, Auth, measurement), OneSignal, Audience Network,
YouTube player, OTPView, CodeView, PatternLockView, WaveSideBar. Their newer versions need minSdk 23 and/or
compileSdk 34+, and the generated manifest (`Ix`, `EditorManifest`) is written for the bundled versions; changing them
needs the android.jar/toolchain step and device runs. They now sit on the newer AndroidX underneath and still build
(fixture 902).

`BuiltInLibraries.java` (shipped in `overlay/`): new names, R packages only for libraries whose `res/` holds real
resources (activity 1.7.2's `view_tree_on_back_pressed_dispatcher_owner` id, poolingcontainer's tags), and **every old
dependency kept**: the set a project gets is a superset of the 1.8.2 set for every component (`check_graph.py`).
AppCompat projects now also get kotlin-stdlib, core-ktx, coroutines and profileinstaller (as any Gradle app with
these AndroidX versions does): about +1.2 MB of dex in the built app.
`Lx` (Android Studio export build.gradle) names the same versions.

Licences of the 49 updated/new libraries, read from their POMs on 2026-10-21: Apache-2.0 for 44 (AndroidX, Material,
Kotlin, coroutines, Gson, auto-value and OkHttp/Okio via their parent POMs); Glide's four artifacts: Simplified BSD +
Apache-2.0; Lottie's POM has an empty `<license/>` (the project, github.com/airbnb/lottie-android, is Apache-2.0, the
same library as the bundled 3.4.0). The same licence families as the 1.8.2 set; no GPL library was added. New code in
this release (tools/, the `Lx` strings) copies nothing from AiTechApp or Sketchware Pro 7.0.0.

jcenter as upstream wrote it, and was not built. The IDE's screens, AAPT2/D8 **on a phone**, installing and starting the built apps, and whether the newer AndroidX
behaves differently at run time on the owner's Android 15 phone. Device checks: build a new project and an existing one
(#644, #623, #606), install, open each screen once; a project with RecyclerView, BottomNavigation, TabLayout+ViewPager,
Glide image and RequestNetwork.
